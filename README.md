# 📱 Global Mobile Phone Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze global mobile phone sales performance across different brands, countries, operators, and distributors.

The dashboard provides insights into:
- Revenue & Profit Analysis
- Brand Performance
- Units Sold
- Margin %
- Operator Sales Share
- Distributor Performance
- Yearly Revenue Trends

---

## 🚀 Tools & Technologies Used
- Power BI
- Excel
- Data Visualization
- DAX Measures
- Data Cleaning

---

## 📊 Dashboard Features

### 1️⃣ Overview Performance Dashboard
- Total Revenue KPI
- Net Profit KPI
- Units Sold KPI
- Margin %
- Revenue & Profit by Brand
- Yearly Revenue Trend
- Country Filters

### 2️⃣ Product & Brand Performance Dashboard
- Units Sold vs Profit Margin
- Top 3 Brand Analysis
- Sales Share by Operator
- Units Sold per Distributor
- Country-Based Filtering

## 📈 Key Insights
- Apple and LG generated the highest revenue.
- LG achieved the highest units sold.
- Revenue peaked significantly in 2021.
- Tuenti had the largest operator sales share.
- Tottus was the top-performing distributor.
